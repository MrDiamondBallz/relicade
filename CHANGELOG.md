# Changelog

## Unreleased — native development milestones (2026-10-24)

These are source milestones, not an official release or complete platform acceptance.

### Added
- Native offline discovery for 10,000 named Wikidata game records, with stable IDs, local search, bounded pages and bundled attribution/provenance.
- Explicit Windows x64 UZDoom/Freedoom engine and data setup, cancellation and retained-data recognition, with Play kept separate and unavailable pending its Windows profile/runtime acceptance.
- Metadata-only library export and inspected portable rollback/backup-cleanup flows.
- Original orange controller-R identity across native assets and repository branding, plus an untouched current native Windows catalog screenshot.

### Fixed
- Windows settings/library persistence invoking unsupported Unix file-mode setters.
- SDL subsystem ownership and late-call handling, modal/menu input routing and cold-card layout regressions.
- Windows generation activation/recovery with exclusive leases and long native paths.
- Pinned catalog-byte preservation in Windows Git checkouts and stale source-opening errors after selection changes.

### Still pending
- Official packages, the branded dependency-complete Windows wizard, automatic launcher updates and big-screen mode.
- Integrated Windows gameplay, full clean-machine/recovery/accessibility acceptance and complete per-platform evidence. Cross-builds are not runtime acceptance; macOS hardware is unavailable and Android SDK setup remains deferred.
- Broader game compatibility and lawful emulator support. Metadata coverage is not a playable-game count.
